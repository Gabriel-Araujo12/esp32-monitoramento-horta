# esp32-monitoramento-horta
Projeto para realizar o monitoramento de uma horta com o uso de um microcontrolador ESP32.

### Introdução
Projeto desenvolvido em 2023 que tem como principal objetivo demonstrar o impacto de uma boa análise exploratória de dados ao desenvolver um sistema inteligente de apoio à decisão médica, focado na predição de risco de óbito em pacientes com Síndrome Respiratória Aguda Grave (SRAG).

O modelo foi criado usando o KNN, algoritmo de aprendizado de máquina supervisionado, e um banco de dados disponibilizado no site OpenDataSUS para agir como a base do conhecimento. Além disso, também foram utilizadas algumas bibliotecas da linguagem Python, como Pandas e Scikit-Learn.

### Motivação
Além da demonstração da etapa de análise exploratória, o objetivo estende-se à tentativa de criar um modelo que seja capaz de auxiliar médicos quanto a pacientes comm problemas relacionados a SRAG, tendo em vista a alta preocupação nesse âmbito oriunda do impacto mundial da doença COVID-19, a fim de evitar pioras em quadros clínicos que podem chegar a uma situação de óbito.

### Atualização em 2025
Uma nova versão do projeto foi incluída em 2025 com diversas correções e melhoras no desempenho, além da inclusão de uma interface que permite adicionar pacientes e seus diferentes dados a fim de predizer a sua possível situação clínica.
