# esp32-monitoramento-horta
Projeto para realizar o monitoramento de uma horta com o uso de um microcontrolador ESP32 conectado a uma rede sem fio e com o envio das informações obtidas para a plataforma AdafruitIO.

Os dados obtidos pelos sensores incluem:

- Temperatura do ambiente;
- Umidade do ambiente;
- Luminosidade do ambiente;
- Umidade do solo.
